# Zovro 
A real-time, full-stack ride-sharing application featuring live driver tracking, proximity matching, dynamic fare estimation, and interactive interactive dashboard layouts.

---

##  Tech Stack

### Frontend
* **React.js** (Vite runtime engine)
* **Leaflet Maps API / OSRM** (Interactive map layers & routing engines)
* **CSS3** (Custom UI system dashboards)

### Backend & Database
* **Node.js & Express** (REST API routing layers)
* **PostgreSQL** (Relational data persistence)
* **JSON Web Tokens (JWT)** (Session authentication)

---
